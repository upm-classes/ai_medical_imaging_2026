# Artificial Intelligence in Medical Imaging: lab notebooks (November 2026)

Google Colab notebooks for the course *AI in Medical Imaging: From Fundamentals to Applications* (UPM / Athens). Student notebooks (with `TODO` cells) are in `notebooks/student/`. Solution notebooks are kept private by the instructor (`notebooks/solutions/` is listed in `.gitignore`).

| Day | Notebook | Topic |
|---|---|---|
| 0 | NB00 | Environment check |
| bridge | NB-B | Python and ML refresher (optional) |
| 1 | NB01, NB02, NB03a | DICOM/HU/windowing, image processing, first PyTorch network |
| 2 | NB03b, NB04, NB05 | Training loop, baseline CNN, augmentation audit |
| 3 | NB06, NB07, NB08 | Evaluation and leakage, transfer learning, U-Net (Montgomery) |
| 4-5 | NB09, NB10 | Explainability and checks; team project template |
| optional | NB-X1 to NB-X4 | Box-prompt segmentation, masked autoencoder, MC dropout, FedAvg |

Tiers inside notebooks: **Core** (everyone), `# [PLUS]`, `# [CHALLENGE]`.
Data: see `data/README.md` and `DATA_LICENCES.md`. No images are stored in this repository.
