# data/

This folder is intentionally empty in the repository. **Do not commit images, masks, DICOM or `.npz` files.**

- MedMNIST / PneumoniaMNIST: downloaded automatically by the notebooks (`medmnist==3.0.2`).
- `montgomery_256.npz` (NB08, NB-X1): enrolled students download it from Moodle and upload it into this folder (Colab: left panel > Files > `data/`). It is not redistributed here.
- Synthetic data for NB01/NB02 is generated in the notebooks.
